## 【セクション1】「一応使える」で止まっていませんか？

Webディレクション歴25年、うちEC運用支援を20年以上やっていると、決まって出会う光景があります。

「うちのサイト、なんとなく数字が伸び悩んでいるんです。どこから直せばいいですか?」

この問いに、明快に答えられるかどうかで、コンサルタントの真価が試されます。でも実は、この問いに答えるのは**極めて難しい**。

なぜか。答えるためには、以下すべてを一気に見なければならないからです。

- **ファーストビュー**：3秒で価値が伝わるか
- **キャッチコピー**：ベネフィットが明確か
- **CTA設計**：迷わず押せるか
- **信頼性訴求**：実績・推薦は十分か
- **フォーム設計**：離脱ポイントはないか
- **料金プラン**：比較しやすく整理されているか
- **ユーザー行動フロー**：訪問→CVまでの導線に穴はないか
- **改善優先度**：何から着手すればROIが最大か
- **競合比較**：業界水準と比べてどうか

これらを1つずつ調べれば答えられます。でも、**実務でそんな時間はない**。

さらに厄介なのは、診断結果を**クライアントに提案する形にまとめる工数**です。「診断できました」で終わらず、「明日から何を、どの順番で直すか」の**提案書レベルの成果物**が必要になる。ここで多くの実務者が、また時間を取られます。

**「診断→提案書」まで一気通貫で欲しい**。しかも数分で。実務者の本音は、ここに集約されます。

## 【セクション1.5】なぜAIに任せると、失敗しがちなのか

「じゃあChatGPTに詳しく聞けばいいのでは?」——ここで多くの実務者が、次の壁にぶつかります。

AIに診断させる時、実はほとんどの人が **同じ失敗** をしています。

### 失敗1：「診断してください」で終わる

URLを貼って「診断してください」とだけ書く。返ってくるのは**教科書的な当たり障りのないアドバイス**です。

> 「ユーザー視点を意識しましょう」「わかりやすいコピーを書きましょう」「CTAは目立つ色に」

——それは知っている。**うちのサイトに固有の話**が欲しいのに。

### 失敗2：診断項目が毎回変わる

AIに「体系的に診断して」と伝えても、質問のたびに **観点が変わります**。今回はUI/UXの話、次回はSEOの話、その次はコンテンツの話。結果、**過去の診断との比較ができず、改善効果が測れない**。

### 失敗3：出力形式が使い物にならない

AIから返ってくるのは **テキストの箇条書き** です。これをクライアント提案書に組み込むには、また **PowerPoint整形の8時間** が必要になります。

### 失敗4：優先順位がつかない

「10個の改善点」を挙げてもらっても、「どれから着手すればROIが最大か」の判断は自分でしないといけません。ここで **経験の差** が出て、初心者は迷子になります。

### 失敗5：一貫した思想が欠ける

毎回異なる観点で診断されると、**「うちのサイトの本質的な課題は何か」の1本の軸** が見えなくなります。

これら5つの失敗は、AIの能力の問題ではなく、**「構造化された指示」と「納品物形式の設計」がないから** 起きています。

UI診断ディレクターは、**これら5つの失敗を、プロンプトエンジニアリングとPPTX生成の仕組みで、まとめて解決** します。

## 【セクション2】この商品が解決すること

UI診断ディレクターは、URLを1本入力するだけで、**9人の専門家視点による診断**を実行し、**3〜5分**で以下の3ファイルを PPTX形式で納品します。

### ① UI診断スコアカード

10項目×5段階評価＋総合ランク（S/A/B/C/D）を、1枚の PPTX で可視化。

- **10項目**：FV / キャッチコピー / CTA / 信頼性 / フォーム / 料金 / 情報設計 / モバイル最適化 / SEO基礎 / ブランド一貫性
- **各項目に**：スコア・所見・強み・課題を明記
- **総合スコア**：50点満点＋ランク表示

用途：**現状の健康診断書**として、経営層への報告や社内共有に使えます。

### ② 改善提案リスト

優先度付き5件の改善提案を、Before/After付きで納品。

- **各提案に**：課題・改善方向・期待効果・実装難易度・目標スコア項目
- **Before/After**：改善前と改善後のイメージを対比表示
- **優先度**：ROI × 実装容易性でランキング

用途：**明日から着手する具体的な改善ロードマップ**として、開発チームや制作会社への発注書に組み込めます。

### ③ ビジュアル診断ボード（3スライド構成）

**メインは Before/After 版（3/3）**。他2枚は補足資料として同梱：

- **3/3 Before/After（メイン）**：現状の課題箇所と改善後のイメージを、視覚的に対比表示
- **1/3 LP構造マップ**：ページ構造・ユーザー行動フロー・改善方向を1枚に統合
- **2/3 スコア視覚化**：10項目のレーダーチャートで強み・課題を俯瞰

用途：**メインの3/3を経営層・クライアント向けプレゼンに、補足の1/3・2/3を実務層・詳細分析用に**使い分けられます。

### 3ファイルすべてに共通する品質

- **PPTX形式**：クライアント提案書にそのまま組み込める
- **Meiryo 14pt以上・NAVY統一デザイン**：ビジネス現場で違和感なく使える
- **1280×720**の標準スライド比率
- **カラーパレット**：NAVY（信頼）× ORANGE（行動喚起）× 3色以内の制約
- **文字数上限厳格化**：120字の長文入力でもレイアウトが崩れない品質保証

## 【セクション3】他のツール・GPTsとの違い

UI診断ディレクターが、既存のツール・サービスと決定的に違うのは、**「診断→納品物」までの一気通貫**にあります。

### vs 汎用GPTs（無料ChatGPT・Gemini等）

- **汎用GPTs**：テキストの診断コメントは返ってくるが、**提案書に組み込める形式ではない**
- **UI診断ディレクター**：PPTX 3ファイルで納品。**クライアント提案の"添付資料"として即座に使える**

### vs Similarweb / SEMrush（月額課金型SaaS）

- **Similarweb等**：月額$125〜、英語UI、トラフィック分析中心
- **UI診断ディレクター**：買い切り、日本語、**UI/UX特化**の実務者向け設計

### vs コンサル発注

- **コンサル**：数十万円〜、納期2〜4週間、範囲交渉が必要
- **UI診断ディレクター**：**ローンチ価格4,980円（通常9,800円）、3〜5分、範囲固定**で即座に手元に届く

### vs 自前で診断書を作る

- **自前作成**：1サイト診断に**8〜10時間**（PowerPoint作成含む）
- **UI診断ディレクター**：**3〜5分**。10サイト診断してもコーヒー1杯分の時間

僕はWebディレクション歴25年、うち業務委託でEC運用支援を20年以上やっている実務者です。SIer出身のエンジニアでも、デザイン畑のデザイナーでもありません。

「コンサルタントが提案書を作るときに、どんな粒度の情報が欲しいか」——これを、**受け取る側と作る側の両方の視座**で設計しました。

だから UI診断ディレクターの納品物は、**明日そのままクライアント提案に持っていける粒度**になっています。

## 【セクション7】よくある質問（FAQ）

### Q1：ログイン画面や会員限定ページも診断できますか？

A：**公開ページのみ対応**しています。認証が必要なページは、スクリーンショット添付での診断も可能です（β機能）。

### Q2：3〜5分で診断できる仕組みは？

A：9つの専門家視点をプロンプトエンジニアリングで並列処理し、10項目のスコアリングを構造化データとして生成、そのデータを PPTX 生成スクリプトに流し込む仕組みです。「診断する AI」と「PPTX を作る PPTX生成器」を分離することで、品質と速度を両立しています。

### Q3：クライアントへの納品に使えますか？

A：**商用利用OK**です。生成された PPTX は、ロゴ差し替え・追記編集自由。制作会社の方は、自社ブランドの提案書として活用いただけます。

### Q4：診断精度は？

A：Webディレクション歴25年・EC運用支援を20年以上の実務者が、これまで携わった100サイト以上の知見をもとに調整しました。**"提案書レベルの粒度"**を維持しつつ、AIの得意分野（構造化・網羅性）を活かした設計です。ただし最終的な戦略判断は、必ず人間が行ってください。

### Q5：アップデートはありますか？

A：**永久無料アップデート**。GPTsの Instructions を継続的に改善し、レイアウト・診断項目も定期的に更新します。

## 【付録B】開発ヒストリー（なぜこのツールが生まれたか）

UI診断ディレクターは、いきなりこの形で作られたわけではありません。

### 2026年4月：最初の試行錯誤

顧客との商談で「うちのサイト、どこから直せばいいですか？」と問われることが、多い月には月に10件を超えていました。ChatGPTに相談しても、当たり障りのない回答しか返って来ない。

「これ、自分で診断フレームワークを作ってAIに流し込めば、もっと一貫した回答が得られるのでは?」——これが出発点でした。

### 2026年5月：10項目スコアリングの確立

自分のWebディレクション・EC運用支援の経験から、**診断に必要な10項目**を洗い出しました。

FV / キャッチコピー / CTA / 信頼性 / フォーム / 料金 / 情報設計 / モバイル最適化 / SEO基礎 / ブランド一貫性。

**この10項目は、クライアントサイトや競合サイトを合わせて月に30〜40件を見ている中で、自分が実際にチェックしている項目そのもの**です。

### 2026年6月：PPTX自動生成への滑り台

AIの診断結果を手作業でPowerPointに入力していては、**1サイトあたりに相当の時間**がかかっていました。ここを自動化することにしました。

調べてみると、PPTX自動生成にはPythonのライブラリがひと通り揃っていることを知りました（僕はコードを書けないので、AIに全部作ってもらいました）。

### 2026年7月：レイアウトとの格闘（実はここが一番大変）

基本機能は完成しましたが、**実際のクライアントに見せられるレベル**には至らなかった。

- 文字がスライド枠からはみ出して切れる
- 重要項目のスコアが枠外にはみ出す
- レイアウトがデータによって崩れる

この問題を一つずつ、**「ここが気持ち悪い」「こう見えてほしい」とAIに伝え続け**、修正し尽くしました。

GMBの時と同じです。「できる」で止まらず、「気持ちよく使える」まで詰めきる。

### v11への到達：体験の質の保証

**レイアウトの実描画基準**で文字数上限を厳密に設計し、120字の長文入力でもレイアウトが崩れないバージョンに到達しました（2026年7月8日）。

ここまで来て、**やっと人に見せられるレベル**になったと思っています。
