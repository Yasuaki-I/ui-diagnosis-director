## 🎯 商品ポジショニング（1文サマリー）

> **「一応使えるサイト」を「思わず進みたくなる体験」に変える、9項目診断×3ファイル納品のGPTs**

- ターゲット：EC/LP運営者・Web制作会社・マーケ担当者
- 提供価値：ChatGPT無料版では出せない「構造化された納品可能な診断レポート」を1回3〜5分で
- 差別化：UI/UX特化 × 3ファイル納品（スコアカード＋改善提案＋ビジュアル診断ボード） × 実務即使用可能なPPTX形式

## 📢 キャッチコピー3案

### 案1：問題提起型（実務者の痛みに刺す）
> **「うちのサイト、どこから直せばいいですか？」**
> ——その1問に、9人分の視点で答えるGPTsを作りました。

**特徴**：クライアントとの会話でよく出る問いを起点にする。制作会社・EC支援の共感を得やすい。

### 案2：ビフォーアフター型（成果訴求）
> **URLを貼るだけで、3〜5分後には「明日から直す10項目」が手元に届く。**
> UI診断ディレクター — 制作会社が"お金を取れる診断書"を、ワンオペで出せる時代へ。

**特徴**：所要時間と成果物を明示。単価が上がる制作会社向けの訴求。

### 案3：物語型（GMB記事からの接続）
> **「保存できます」で満足できなかった僕が、次に作ったもの。**
> ——AIに、Webサイト診断を"納品物レベル"でやらせる方法。

**特徴**：GMB note記事の読者層をそのまま流し込める。ブランド一貫性が最強。

**→ 僕の推奨は【案3】**：GMB→UI診断の導線を最も自然に繋げられる。GMB記事末尾の「実際に僕が使っているツールと一緒にお届けします」の伏線を回収する構造。

## 📖 商品説明骨子（本文構成案）

### セクション1：「一応使える」で止まっていませんか？（共感パート・約400字）
- ECサイト運営で「なんとなく数字が伸び悩む」経験
- 「どこから直せばいいか分からない」が最大の課題
- ChatGPTに聞くと汎用的な答えしか出ない。「うちのサイトに固有の話」にならない

### セクション2：この商品が解決すること（提示パート・約500字）
- URLを入力するだけで、9項目の専門家視点で診断
- 3〜5分で3ファイルが手元に届く：
  - **① UI診断スコアカード**（10項目×5段階評価＋総合ランク）
  - **② 改善提案リスト**（優先度付き5件、Before/After付き）
  - **③ ビジュアル診断ボード**（LP構造マップ＋ユーザー行動フロー＋改善方向）
- PPTX形式なので、そのままクライアント提案書に組み込める
- Meiryo 14pt以上・NAVY統一デザインで、ビジネス現場で違和感なく使える

### セクション3：他のツール・GPTsとの違い（差別化パート・約400字）
- **vs 汎用GPTs**：構造化された納品可能形式（PPTX 3ファイル）
- **vs Similarweb/SEMrush**：月額課金なし、日本語UI/UX特化
- **vs コンサル発注**：数十万円→5,000円で診断書入手
- **開発者の背景**：業務委託でEC運用支援10年、実務者の視点で設計

### セクション4：実物サンプル（信頼構築パート）
- スコアカード実物（画像）
- 改善提案リスト実物（画像）
- ビジュアル診断ボード実物（画像）
- 「120字の長文でもレイアウトが崩れない」品質保証の説明

### セクション5：こんな人に使ってほしい（ターゲット明示・約300字）
- EC/LP運営者：自社サイトを月1回セルフ診断
- Web制作会社：提案時の"診断書"として活用、単価向上
- マーケ担当者：クライアントへの改善提案の土台に

### セクション6：使い方（3ステップ・約200字）
1. GPTsに診断したいURLを送る
2. 3〜5分待つ
3. PPTX 3ファイルを受け取る → 提案書に組み込む

### セクション7：価格と特典（決済誘導パート）
- **ローンチ価格：4,980円**（先着30名）
- 通常価格：9,800円
- 特典：
  - 使い方PDFガイド
  - 商用利用OK（クライアント納品可）
  - アップデート永久無料

## 🖼️ CTA画像7 構成メモ（入江さんの画像制作用インプット）

┌────────────────────────────────────────────────────────┐
│  [左1/2：予告テキスト]        [右1/2：診断ボード実物イメージ]  │

│  次回：「使い勝手」の             ┌──────────────┐        │
│  本丸の話をします。               │ ビジュアル診断  │        │
│                                   │  ボード実物     │        │
│  ──────                          │  （スコア85点   │        │
│  URLを貼るだけで、                │   Top3課題等）  │        │
│  9項目の診断レポートが            └──────────────┘        │
│  3〜5分で手元に。                                          │
│                                    ▲ 実物イメージ         │

**メインコピー**：
> 次回：「使い勝手」の本丸の話をします。

**サブコピー**：
> URLを貼るだけで、9項目の診断レポートが3〜5分で手元に。

**フッター**：
> UI診断ディレクター（GPTs）— 近日Brainにて公開予定

- **カラー**：GMB note全体のトーンに合わせて、ネイビー＋オレンジ＋ホワイトの3色構成

- GMB記事の落ち着いた実務系トーンを継承
- 「次回予告」の位置付けなので、興味を残す程度で十分
