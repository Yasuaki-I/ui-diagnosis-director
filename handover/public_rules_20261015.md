## ■ 1. 区分の定義
| 区分 | 定義 |
|---|---|
| 積極公開 | note・X などで自由に発信してよい |
| 条件付き公開 | 説明のための抜粋・構造の説明にとどめる。**購入者限定の範囲（コード・定数の逐語）を超えない** |
| 🆕 購入者限定 | 販売契約に基づき購入者に限って提供する。**無償公開は行わない。購入者による再配布・転載・転売は認めない**（販売ページ r2 827行の文言と対応） |
| 非公開 | 購入者を含め、外部に出さない |

## ■ 2. 対象ごとの区分
### 積極公開
- 判断過程
- 設計思想
- 仕様の全体像
- 失敗事例と学び
### 条件付き公開
- Instructions 抜粋
- builder 構造説明レベル
### 購入者限定
- builder フルコード（販売版 v17_217＝`47629772eaff`）
- 内部定数（builder に含まれる分。図解パターン仕様書が逐語で載せる `DIAGNOSIS_TO_PATTERN` を含む）
- schema のうち、builder・図解パターン仕様書に含まれる必須キーの記述
- 手順書（ローカル Python で使う場合）
- 図解パターン仕様書（PLAIN 抜粋版）
### 非公開
- lite 版全文（GPTs 本体の Instructions）
- 🆕 PLAIN 全文（購入者には抜粋版のみ）
- schema 完全形（`visual_data_schema.md` 本体・同梱しない）
- βFB 詳細
- 三田様関連の具体情報
- 紹介案件情報
