## 🧭 判断根拠（Claude-Chat 7/28回答による4軸判定を踏襲・rev2で競合分析根拠を追加）

### v3.5コア（バナー掲載媒体診断）を先に置く理由

**rev1の3根拠：**
- 実力可視化に高効果／エージェント層に伝わる
- 実務ユーザーの利用価値・改善価値に直結しやすい
- 02の再定義（実力可視化装置）と直接整合

**rev2追加根拠（NEW）：**
- 競合まとAIは掲載媒体考慮を「実機確認してね」の口頭注意で片付けている
- UI診断ディレクターは**ヒアリング段階で掲載媒体・位置を訊いて診断に反映**する設計
- これは"やっているようで、競合はまだ実装していない"領域
- **v3.5コアは"差別化の芯"として一段と重要**

### B-5（10項目スコア色分け）を後追いにする理由

**rev1の4根拠を維持：**
1. クリティカルパス保護（v3.5コア8/15期日死守）
2. 戦略的位置づけ（見栄え向上／実力可視化への直接効果は中程度）
3. 発信ネタとしての価値（地味）
4. 物理干渉リスク（Phase B非コード系との違い）

**rev2追加根拠（NEW）：**
- 競合まとAIの武器は「画像アウトプット1枚」だが、**業務利用の意思決定要因ではない**（クライアント提出は結局PPTX/PDF）
- 画像出力への対抗軸として B-5 を前倒しする合理性は低い
- B-5 は "画像対抗" ではなく "**PPTX内の情報構造化強化**" として位置づけるべき
- **rev1判断「B-5後追い」は維持・強化**

## 🔧 Phase B（B-1〜B-4）の記述トーン方針【NEW】

競合まとAIの言語化品質（判断基準明示型）に **追随・超越** すべく、Phase B成果物の記述トーンを以下で統一：

### 統一ルール

- 抽象論・箇条書きだけの列挙は避ける
- 各項目に「**なぜそうするか**」の判断基準を必ず添える
- 数値・位置・媒体特性まで踏み込む具体指示（曖昧語禁止）
- 実装後の**検証ステップ**も可能な限り併記

### 適用対象

| 成果物 | 適用の重点 |
|---|---|
| **B-1**（web-director-condensed.md・15KB以内） | 判断基準明示・条件付き適用の"if-then"構造化 |
| **B-2**（digital-agency-guidebook-summary.md） | ガイドブックの原理原則を"なぜ"の根拠として引用可能な形に |
| **B-3**（diagram-patterns-catalog.md） | 12種パターン各々に「使う場面／使わない場面」の判断基準を添える |
| **B-4**（ppt-visual-catalog スキル） | 実サンプルPPTX＋設計意図の言語化をセット |
