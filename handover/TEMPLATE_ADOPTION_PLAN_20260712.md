| # | ファイル | 用途 | ページ | 使える主要パーツ |
|---|---|---|---|---|
| 01 | 大全v2_01_提案書.pptx | BtoB提案書 | 14P | 3つの理由カード / So What構造 / 投資回収グラフ / 運用の3原則 |
| 02 | 大全v2_02_報告書.pptx | 業績報告 | 12P | 表紙巨大数字 / KPI3カード / 折線推移 |
| 03 | 大全v2_03_サービス紹介.pptx | サービス紹介 | 12P | **課題3声カード / 提供価値3カード / 3ステップ操作** |
| 04 | 大全v2_04_会社紹介.pptx | 会社紹介 | 12P | 沿革タイムライン / 数字ハイライト |

**共通デザイン特徴**：
- カラー：ネイビー基調＋オレンジアクセント（**UI診断ディレクターv15の配色と完全整合**）
- タイポグラフィ：見出し太字＋本文明瞭・脚注「注：」「出所：」の運用ルール確立
- 情報設計：「事実の見出し／解釈は別枠」「So What で結論明示」というコンサル系フレーム内蔵
- 保存先：`_reference/pptx_templates/`
- 構造解析済：`_reference/_analysis/{proposal, report, service, company}/`

### グラフ設計プロンプトの内容

- 保存先：`_reference/prompts/グラフ設計_プロンプト.txt`
- 役割：元コンサルのデータ設計者として、12種類のグラフから最適選択
- ロジック：見せたい要素（差／推移／割合／増減／...）を判定 → グラフ選択 → 軸設計 → 事実と解釈の分離 → 強調ポイント特定
- 制約ルール：立体禁止／円は5項目以下かつ過半確認時のみ／カテゴリ比較に折線禁止／実績と見込みの実線/破線分離
- **完成度**：即Instructions組み込み可能な論理性

## 2. UI診断ディレクターへの適用可能性（3レベル評価）

### レベル1：LP販売ページ用ビジュアル素材（**強く推奨**）

Brain販売ページのフェーズ2図版制作5点の一部を **テンプレ流用** で賄う。

| LP用途 | 流用元 | 加工内容 |
|---|---|---|
| 提供価値3点（速い・揃う・見える） | 03サービス紹介 slide 5 | 文言差替のみ |
| 課題訴求3声 | 03サービス紹介 slide 2 | 文言差替のみ |
| 3ステップ操作の流れ | 03サービス紹介 slide 6 | 文言差替のみ |
| 時間削減効果グラフ | 01提案書 slide 11 | 数値差替＋グラフ形状維持 |
| So What構造の提案書サンプル | 01提案書 slide 2 | 部分抜粋 |

**効果**：
- ビジュアル戦略14点構成のうち「図版5点」の負担が **激減**（テンプレ流用でトリミング＋文言差替のみ）
- 初版9点方針の「実物サンプル4点＋図版5点」のうち、図版5点が今日から確保可能
- 制作工数の見積：**AI画像生成4点分の工数を丸ごと不要にできる**可能性

### レベル2：GPTs出力の第二パスとして組み込み（v16以降・慎重検討）

- 現状の診断PPTX v15はそのまま維持
- **追加**：GPTs → 「提案書テンプレ準拠の拡張版PPTX」を第二出力として生成
- 特に「改善提案リスト」は提案書テンプレの構造（課題→So What→解決策→効果）にフィット

**メリット**：
- 商品価値の底上げ（診断＋提案書レベルの2種類納品）
- Brain販売ページで「これも付いてくる」の追加特典化

**懸念**：
- 開発工数中〜大（テンプレのプレースホルダー方式に python-pptx を対応させる技術検証必要）
- 8月中旬発売に **間に合わない可能性が高い** → 発売後の追加機能として位置づけるのが現実的

### レベル3：診断PPTXそのものをテンプレ準拠に書き換え（**非推奨**）

- v15までの投資が無駄になる
- 診断結果は動的コンテンツで、テンプレの静的レイアウトと相性が悪い
- **却下**

## 3. グラフ設計プロンプトのInstructions組み込み（別軸で強く推奨）

### 活用先A：UI診断ディレクター Instructions への統合（v16機能）

現状の Instructions は「診断結果」を出すだけで、グラフ設計判断まで踏み込んでいない。

**組み込み案**：
- 診断で数値情報が出た場合の「グラフ化推奨」判定を Instructions に追加
- 12種類のグラフから最適選択のロジックを内蔵
- 「事実の見出し／解釈は別枠」の分離を Instructions のC-3ビジュアルボード生成に組み込み

**効果**：
- **商品品質の底上げ**：「AIが単に診断するだけ」から「AI が最適なビジュアル設計まで踏み込む」商品へ
- 差別化ポイント：Similarweb / SEMrush 等の月額SaaSにはない「診断＋ビジュアル設計」の統合価値

### 活用先B：LP販売ページで「AI品質」を実演する素材

- 「素人プロンプトで作ったグラフ」vs「このプロンプトで作ったグラフ」の並列比較
- Brain販売ページの信頼性訴求として強力
