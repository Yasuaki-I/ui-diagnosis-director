**対象**: Brain販売ページ最上部のAI生成ヒーローバナー画像に載せるキャッチコピー
**ターゲット**: Brain読者（中小企業EC/LP運営者・制作会社・フリーランス・Webディレクター）
**制約**: 2短行・各行最大15字
**軸**: GMB連続性 / 機能ベネフィット / コンセプト

## 3案の設計思想

### 共通の設計基準（全案共通）
- **1行目**：問い・状況・課題の投げかけ（感情に触れる）
- **2行目**：解決・変化・成果の提示（機能／結果を示す）
- **接続**：句読点や改行で「間」を生み、視線誘導する
- **禁じ手**：「AIで」「GPTsで」といった **手段の羅列**（"How"）は避ける
- **重視**：**"After"の姿**（読者がこのツールで何を得られるか）を明示

## 【案①】GMB連続性軸

### コピー
```
"保存できる" のその先へ。
"納品できる" 診断を10分で。
```

### 設計意図
- **1行目**：GMB note のタイトル「保存できます、では満足できなかった話」を **明示的に引用**し、note読者に「あの続きだ」と即認識させる
- **2行目**：GMB=Chrome拡張が"個人の保存"を扱うのに対し、UI診断ディレクター=PPTX3ファイル納品が"クライアント納品"を扱うと **対比明示**
- **キーワード**："保存"→"納品" の言葉のリズムで **道具の進化** を示す

### 訴求ロジック
- GMB note経由の読者に対する **物語型接続**（あの記事の続きだ）
- "納品"という単語で **業務利用の実装** を明示
- "10分"という具体的数値で **時間削減効果** を示唆

### 効果予測
- **GMB note経由の読者**：極めて高い訴求力（続報として即クリック）
- **GMB note未読の読者**：やや弱い（"保存できる"の文脈が伝わりにくい）

### 字数チェック
- 1行目：11字 ✅（15字以内）
- 2行目：14字 ✅（15字以内）

## 【案②】機能ベネフィット軸

### コピー
```
URLを送って、3〜5分。
提案書レベルの診断書が届く。
```

### 設計意図
- **1行目**：**操作の圧倒的な単純さ**を最初に見せる（URLを送るだけ）
- **2行目**：**成果物の質**を「提案書レベル」の一言で保証（クライアント納品可能な品質）
- **キーワード**："送って"→"届く"の受動→能動→受動リズムで **自動化された納品体験** を演出

### 訴求ロジック
- 一目で "What is it?" が伝わる **機能明示型**
- "3〜5分"という **具体的時間** で信頼感を担保
- "提案書レベル"という **業界共通言語** で品質を保証

### 効果予測
- **GMB note未読の読者**：極めて高い訴求力（機能が即座に伝わる）
- **BtoB購入意思決定者**：高い訴求力（"提案書"というワードに反応）
- **物語性を好む読者**：やや弱い（機能的すぎる）

### 字数チェック
- 1行目：11字 ✅（15字以内）
- 2行目：14字 ✅（15字以内）

## 【案③】コンセプト軸

### コピー
```
"一応使える"を、
"提案できる"に変える。
```

### 設計意図
- **1行目**："一応使える" というBrain記事本文の **キーコピー** を最初に見せる
- **2行目**："提案できる" という **業務価値** への転換を明示
- **キーワード**："一応使える"→"提案できる" の一言変換で **道具の使命** を象徴

### 訴求ロジック
- 本文の思想を **1本の軸** に集約した象徴的コピー
- "使える"→"提案できる"で **業務利用への進化** を明示
- 抽象度が高いが、Brain記事全体の哲学を **入口で提示**

### 効果予測
- **経営層・意思決定者**：極めて高い訴求力（コンセプトで意思決定する層に刺さる）
- **業務利用を検討している読者**：高い訴求力（"提案できる"が刺さる）
- **具体機能を知りたい読者**：やや弱い（具体性が薄い）

### 字数チェック
- 1行目：8字 ✅（15字以内）
- 2行目：11字 ✅（15字以内）

## 【僕の推し】

**基本推し：案①（GMB連続性軸）**

理由：
1. **7/18 GMB note公開** との連続性が最強
2. Brain販売ページに来る初期読者の多くが **note経由** と想定される（初動集客の柱）
3. **物語型接続**は初期購入者の熱量を高める効果が大きい

**サブ推し：案②（機能ベネフィット軸）**

理由：
- GMB経由でない読者（X訴求・他ルート）にも即座に伝わる
- **SEO/検索経由の新規流入**にも耐性がある
- ヒーローバナー以外に、**サムネイル・X投稿画像・OGP画像**にも流用しやすい

**ハイブリッド案**：
- ヒーローバナー本体は **案①** を採用
- サムネイル・X投稿画像には **案②** を採用
- 場所で使い分けることで、GMB経由者と新規読者の両方に対応可能
