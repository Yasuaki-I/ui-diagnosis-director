## 📋 このアップデートで何が変わるか

### 一言で
**リスト表示の「折返しの見た目」が根本改善します。**

### 具体的な変化（3つ）

1. **強み・課題の折返しが自然に**
   - v14：「明確な CTA ボタンとファーストビュー設 / 計」← 「設」と「計」が離れて見える
   - v15：「明確な CTA ボタンとファーストビュー設 / 計」← 「設」と「計」が詰まって1文の続きに見える

2. **総評帯の天地余白が均等に**
   - v14：総評テキストが枠の上寄りで、下側が窮屈
   - v15：天地に均等な余白ができて、見やすさアップ

3. **項目間の余白が明確に**
   - v14：折返しの行間と項目間の余白が同じで、リストの区切りが弱い
   - v15：折返しの行間は詰まりつつ、項目間には明確な余白ができて、リストの視認性アップ

### 反映しないとどうなるか
- 7/18 GMB note公開後、購入検討者がツールを試した時に **v14のレイアウトを体験**することになる
- Brain販売ページに載せる実物サンプル画像（v15画像化予定）と、購入者が実際に受け取るPPTX（v14出力）の **見た目に差**が生じる
- 「販売ページで見た品質と、実際にAIから受け取ったPPTXの品質が違う」と感じられる可能性がある

### 反映すると何が良くなるか
- Brain販売ページの実物サンプルと、購入後の実出力が **完全整合**
- 「販売ページの見本通り」の品質が保証される
- **発売準備段階でv15品質のGPTsが稼働** → 購入者の最初の体験がv15クオリティに

## 🚀 実施手順

### Step 1：現状のGPTs管理画面を開く

1. ブラウザで `https://chat.openai.com` にログイン
2. 左サイドバーの「**Explore GPTs**」または「**My GPTs**」をクリック
3. **UI診断ディレクター** を選択
4. 右上の「**Edit GPT**」（または「編集」）ボタンをクリック
5. 「**Configure**」タブが表示されることを確認

### Step 2：Knowledge セクションの旧ファイルを確認

1. Configure タブ内の「**Knowledge**」セクションまでスクロール
2. アップロード済みファイル一覧を確認
3. **`03_pptx_builder.py` があることを確認**
4. ファイル名の横の「**×**」または「**削除**」ボタンをクリック
5. 旧版 `03_pptx_builder.py` を削除

### Step 3：v15版 `03_pptx_builder.py` をアップロード

1. Knowledge セクションの「**Upload files**」ボタンをクリック
2. プロジェクトの `gpts-package/03_pptx_builder.py` を選択
3. アップロード完了を待つ（数秒〜10秒程度）
4. Knowledge一覧に **新しい `03_pptx_builder.py`** が表示されることを確認

### Step 4：変更を保存

1. 右上の「**Update**」または「**保存**」ボタンをクリック
2. 「Only me」または「Anyone with a link」のいずれかを選択（既存設定を維持）
3. 「Confirm」または「確認」ボタンをクリック
4. 「GPT updated」または「更新完了」の通知を確認

### Step 5：動作テスト

新しいチャットセッションを開いて、動作テストを実施します。

#### テスト用入力サンプル

以下のいずれかで動作テストしてください：

**テスト1：URL診断（実サイト）**
```
https://openai.com を診断してください
```

**テスト2：架空URL**
```
https://example.com を診断してください
```

（※ 架空URLだとブラウジングが失敗する可能性があるため、テスト1推奨）

#### 期待される出力

1. **3ファイル（PPTX）が生成される**
   - `01_UI診断スコアカード_{サイト名}.pptx`
   - `02_改善提案リスト_{サイト名}.pptx`
   - `03_ビジュアル診断ボード_{サイト名}.pptx`

2. **各ファイルをダウンロードして開く**
   - PowerPoint / Keynote で開く
   - 3ファイルすべてが正常に開ける

3. **v15の変化が反映されているか確認**
   - **C-3 slide1（ビジュアル診断ボード 1枚目）** を開く
   - **「◎ 強み（活かすべき点）」** の項目を確認
   - 強みの項目文が折返している場合、**折返し行が詰まっている**ことを確認
   - 項目間には **明確な余白** があることを確認
   - **中央の「◤ 総評」帯** を確認、テキストが **天地の中央** に配置されていることを確認

## 🆘 トラブル時の対応

### ケース1：アップロードでエラーが出る
- ファイルサイズを確認：170 KB程度・問題なし
- ネットワーク接続を確認
- ブラウザを再読み込みして再試行

### ケース2：動作テストで PPTX が生成されない
- ChatGPTの「Code Interpreter」が有効か確認
- Configure画面の「Capabilities」で「**Code Interpreter & Data Analysis**」がONになっているか確認
- （ONでなければONに変更して Update）

### ケース3：v15の変化が反映されていない（v14のような見た目）
- **原因1**：旧版ファイルの削除漏れ → Knowledge内に古い `03_pptx_builder.py` が残っていないか再確認
- **原因2**：ChatGPTのキャッシュ → 新しいチャットセッションを開いて再テスト
- **原因3**：ブラウザキャッシュ → シークレット/プライベートウィンドウで再テスト

### ケース4：C-3 slide1 の総評帯で文字がはみ出す
- 稀に、テストデータの総評文が17字を超える場合がある
- 現状のGPTsは17字上限で自動切り詰めするため、ユーザー入力によっては発生しない
- 継続的な問題が発生する場合は、僕（UI診断ディレクター側）に連絡

### ケース5：反映後、購入者から不具合報告があった場合
- **即座に旧版に戻すことは不可能**（Knowledge削除→再アップロードの手間）
- ただし、v15はv14の全機能を継承しているため、**新たな不具合が発生する可能性は極めて低い**
- 万が一の場合、僕に連絡いただければ即座に対応します

## 📊 v14 → v15 差分（技術詳細・参考）

一般利用者への説明では不要ですが、記録のため詳細を記します。

### コード変更点

| 変更箇所 | v14 | v15 |
|---|---|---|
| `_add_multi_run_box` 関数 | line_height のみ | line_height + **space_after_pt + space_before_pt + vertical_anchor** |
| `add_paragraph_box` 関数 | line_height のみ | line_height + **space_after_pt + space_before_pt** |
| C-1 One-Pager 強み | line_height=1.6 | line_height=1.2, **space_after_pt=8** |
| C-1 One-Pager 課題 | line_height=1.6 | line_height=1.2, **space_after_pt=8** |
| C-3 slide1 Top3 | line_height=1.35 | line_height=1.2, **space_after_pt=8** |
| C-3 slide1 強み3点 | line_height=1.7 | line_height=1.2, **space_after_pt=8** |
| C-3 slide2 強み・課題コンパクト | line_height=1.7 | line_height=1.2, **space_after_pt=8** |
| C-3 slide1 総評帯 | SUMMARY_H=62, vertical_anchor未設定 | SUMMARY_H=68, **vertical_anchor=MIDDLE** |

### コード仕様の安定化

v15を境に以下を **仕様の方針側（安定領域）** として確定：

> 今後は文字数上限の細かな調整ではなく、
> **`vertical_anchor` / `space_after_pt` / `line_height` の3パラメータで制御** する運用へ移行

Claude-Chatとの合意事項です。
