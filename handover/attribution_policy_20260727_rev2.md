## 🎯 なぜこのルールが必要か（変更なし）

7/26に3参考資料を組み込む方針が固まったが、それぞれ**著作権・利用条件・出所が異なる**。以下の3つを混同したまま運用すると：

- **信頼性リスク**：出典を曖昧にしたまま「デジタル庁ガイドブック準拠」等の権威付けをすると、後で指摘される
- **契約リスク**：うちた氏許諾内容の記録がない状態で商用利用を続けると、条件変更時にトラブル
- **発信リスク**：note/X発信で「Claude Skillとして自作した」と誤解を招く表現をすると入江さんの信用に関わる

そのため、資料ごとに明確な出典表記ルールを定める。

## 📝 資料別 出典表記ルール

### 1. デジタル庁ガイドブック（rev2で更新）

#### ライセンス条件の確定（rev2追記）

**PDL1.0（公共データ利用規約 第1.0版）**：
- 編集・加工して利用する場合 → **義務としての出典明記は不要**
- 編集・加工せず公開する場合 → 出典記載必須

UI診断ディレクターは「builder v16辞書化して独自描画に使う」ため、**義務としての出典明記は不要**。

**ただし、透明性・信頼性担保のため、以下の運用ルールを継続する**：

#### コード内コメント（builder等）
```python
# ============================================================
# デジタル庁 公式カラーパレット（Phase A-1）
# 出典：デジタル庁 ダッシュボードデザインの実践ガイドブックとデザインテンプレート
# https://www.digital.go.jp/resources/dashboard-guidebook
# ライセンス：PDL1.0（公共データ利用規約 第1.0版）
# GitHub：https://github.com/digital-go-jp/policy-dashboard-assets
# 取得日：2026-07-27
# ============================================================
```

#### プロダクト内表示（GPTs出力・PPTX等）
- **診断結果の権威付けに使用OK**：例）「本診断はデジタル庁ガイドブックに準拠したカラーパレットを採用」
- **必須記載事項**（義務ではないが運用として継続）：
  - 出典名：「デジタル庁 ダッシュボードデザインの実践ガイドブック」
  - URL：https://www.digital.go.jp/resources/dashboard-guidebook
- **PPTX内での配置**：C-3ビジュアル診断ボードのフッター補足欄、または統合版の最終ページ「参考資料」欄

#### 発信（note/X）
- **積極的に出典明記して活用OK**：「デジタル庁ガイドブックを、UI診断ディレクターにこう組み込みました」等の発信ネタとして有効
- **注意点**：デジタル庁が推奨・監修していると誤解を招く表現は避ける（「準拠」「参考」「引用」は可、「推奨」「認定」「監修」は不可）

#### 公式出典記載例（rev2）
```
出典：デジタル庁 ダッシュボードデザインの実践ガイドブックとデザインテンプレート
https://www.digital.go.jp/resources/dashboard-guidebook
ライセンス：PDL1.0（公共データ利用規約 第1.0版）
```
