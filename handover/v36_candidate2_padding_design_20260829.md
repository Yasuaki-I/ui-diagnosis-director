## ■ 2. 🔴 真の原因｜`timeline` カード内レイアウトの機械算出

### 原本参照行｜L5295〜5310（`draw_timeline`）

```
card_h = 104                                            # L5276
_v17_card(slide, cx, cy, card_w, card_h, fill_hex, palette)   # L5295
pad = 10                                                # L5298
add_text(... cy + 7  ... 15pt, height_px=22)             # L5299  ラベル
cur = cy + 31                                            # L5302
add_text(... cur ... 18pt, height_px=26)                 # L5304  スコア
cur += 28                                                # L5306
if desc and cur + 20 <= cy + card_h - 6:                 # L5308  描画ガード
    add_text(... desc, 14, height_px=cy + card_h - cur - 6)   # L5310
```

### ⭐ 機械算出（カード上端を0とする）

| 要素 | top | 高さ | 下端 |
|---|---:|---:|---:|
| ラベル（15pt） | ⭐ **7** | ⭐ **22** | ⭐ **29** |
| スコア（18pt） | ⭐ **31** | ⭐ **26** | ⭐ **57** |
| ⭐ **説明文（14pt）** | ⭐ **59** | 🔴 **39** | ⭐ **98** |
| ⭐ **カード下辺** | — | — | ⭐ **104** |

⭐ **ボックス基準の下部余白＝6px（＝L5310 の `- 6` が効いている）。** 🔴 **したがって「6pxを確保する」という案Cの前提は既に満たされている。**

### 🔴 不足しているのは枠高

| 項目 | 値 |
|---|---:|
| ⭐ **説明文ボックスの高さ** | 🔴 **39px** |
| ⭐ **14pt × 2行の必要高**（⭐ pt→px 換算 1.333／行間既定 1.2 相当） | 🔴 **44.8px** |
| 🔴 **不足** | 🔴 **5.8px** |

⚠️ **`auto_size=NONE` のため、この5.8pxは「切れる」のではなく「枠外へ描画される」。** ⭐ **結果として2行目がカード下辺へ接近し、⚠️ 縮小画像では溢れて見える。**

### ⭐ 案C' の設計

⭐ **`add_text` に引数 `min_lines` を追加する（既定 1｜⚠️ 既定値では現行と完全に同一挙動）。**

```
# 設計案（⚠️ 本日はコード変更を行わない｜設計のみ）
def add_text(slide, left_px, top_px, width_px, text, size_pt, *,
             ..., height_px=None, line_height=None, min_lines=1, ...):
    if height_px is None:
        _lh = line_height or 1.2
        height_px = max(int(size_pt * 1.333 * _lh * min_lines), 24)
```

⭐ **呼び出し側（説明文のみ）は下部余白を明示的に確保した式へ揃える。**

| パターン | ⭐ 変更後の式（設計） |
|---|---|
| 🔴 **`timeline`** | 🔴 **`height_px=max(cy + card_h - cur - PAD_BOTTOM, _need(14, 2))`** |

⚠️ **`timeline` は枠高が 44.8px 必要なのに対し card_h=104 では 39px しか取れない。** ⭐ **したがって `timeline` に限り `card_h` の見直し（案A の 116px）が併せて必要になる。**

### ⭐ 案C' と案A の関係
