## `terminator.jp` の戦略的価値

- **短く覚えやすい**（4音節・.jpの権威性）
- **抽象性が絶妙**：「Terminator = 終わらせる者」= 課題を終わらせる Webディレクターの世界観
- **拡張性が高い**：GMB / UI診断 / 将来の第3弾以降を同じ傘下に置ける
- **ドメインオーソリティが集中蓄積**：SEO/権威性で有利
- 「terminator.jp」がブランド名として認知される

## STUDIO導入の技術セットアップ手順

### ステップ1：STUDIO アカウント登録
- https://studio.design/ja
- Google or メールアドレスで登録
- Basic プラン契約（月980円）

### ステップ2：プロジェクト作成
- 新規プロジェクト作成
- テンプレート選択 or 白紙開始（推奨：白紙で私が設計提示）

### ステップ3：DNS設定（`terminator.jp` を STUDIO に向ける）
現在メール利用中とのことなので、**MXレコードは維持**したまま、以下を追加：

- `A レコード`: `@` → STUDIO 指定の IP アドレス
- `CNAME レコード`: `www` → STUDIO のホスト名
- `MX レコード`: **現状のまま維持**（メール受信を止めない）

### ステップ4：SSL認証
- STUDIO が自動発行（Let's Encrypt）
- 数分〜数十分で有効化

**作業時間目安**：DNS設定 30分 + STUDIO 側設定 15分 = **45分**

## 補足：Phase 1 LP を「まず作る」意味

いきなり個人ポータル全体を作らず、**LP を1ページだけ最速で公開**する意味：

1. **リスト構築を1日でも早く始める** → 8月上旬発売判断の材料が増える
2. **note先行公開との連携** → GMB note末尾からLPへの導線を確立
3. **本気度の証明** → 独自ドメインLPは「販売本気モード」の記号
4. **段階的な学習** → STUDIO操作に慣れながら、後で個人ポータル化

Phase 1 LP は **A4サイズ縦に収まる程度の情報量**で十分。凝りすぎない。
