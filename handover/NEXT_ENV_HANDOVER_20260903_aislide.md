## ■ 6. ⭐ AIドライブ 書込手順（⭐ 実測済・21往復目に7点で検証）

```python
import os, hashlib
A = '/mnt/aidrive/ui-diagnosis-director/handover'
def md5(p): return hashlib.md5(open(p, 'rb').read()).hexdigest()[:12]

data = open(src, 'rb').read()
open(os.path.join(A, name), 'wb').write(data)   # 🔴 推奨方式（chmod を伴わない）
assert md5(src) == md5(os.path.join(A, name))   # 🔴 第11条（省略不可）
```

| 方式 | 判定 |
|---|:---:|
| 🔴 **`open(dst,'wb').write()`** | 🔴 **推奨（最速）** |
| ⭐ `shutil.copyfile` | ⭐ 可 |
| ⚠️ **`shutil.copy` ／ `copy2` ／ `cp -p`** | ⚠️ **使わない（⭐ Errno30）** |

🔴 **`OSError: [Errno 30] Read-only file system` は「書込失敗」ではない。** ⭐ **バイトは既に正しく書けており、⭐ 直後の chmod だけが失敗している。⚠️ md5 を確認し、⭐ 一致なら成功として扱う。**

⭐ **配置先**：⭐ 成果物・記録 → `handover/`／⭐ 配布物 → `gpts-package/`
