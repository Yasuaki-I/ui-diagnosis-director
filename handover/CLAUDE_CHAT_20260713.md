## 📅 相談事項2：発売スケジュール再設定（8月中旬 → 9月上旬案）

### 【背景】
考察ドキュメントの最重要指摘：
- 現状の付録C「想定コメント」は **販売信用材料にならない**（例示と明記されているため）
- **βテスター3〜5名からの実レビュー収集が必須**
- βテストを実施しない場合、購入者から「実際のレビューではない」と警戒される可能性

### 【入江さんの問題提起】
1. βテスターは実施したい（原稿信用度のため必須）
2. しかしβテスターが集まるか不透明（無名段階では応募が集まらないリスク）
3. **GMB note公開（7/18）後の方が応募可能性が高い**（noteで存在を知った読者が候補になる）
4. **8月中旬発売では時間的に不可能**、後ろ倒しの必要あり

### 【スケジュール再設計3案】

#### 案A：8月末発売（最短プラン）
```
7/18       : GMB note公開・βテスター募集告知
7/19-7/25  : βテスター募集（1週間）
7/26-8/8   : βテスト実施（2週間）
8/9-8/15   : v6稿作成（実レビュー反映）
8/16-8/22  : 発売準備最終確認
8/23-8/31  : 発売
```
**懸念**：βテスト実施2週間は短い可能性

#### 案B：9月上旬発売（推奨プラン・僕らの基本推し）
```
7/18       : GMB note公開・βテスター募集告知
7/19-8/1   : βテスター募集（2週間）
8/2-8/22   : βテスト実施（3週間・実サイトでの本格利用可能）
```

**メリット**：βテスト充実・7/18 note公開との連続性維持

#### 案C：9月中旬発売（安全プラン）
```

7/19-8/8   : βテスター募集（3週間）
```

### 【入江さんと僕の推し】
**基本方針：案B（9月上旬発売）**

理由：
1. βテスト2週間は業務多忙な実務者には短い可能性
2. 7/18 note公開との連続性維持（1.5ヶ月なら記憶保持）

4. お盆期間中もβテスト実施期間として活用可能

```

グループ2（8/1-8/8募集・8/9-8/22実施）：一次募集で応募しなかった候補者向け
```

#### 案② 実務品質軸
```

URL1本で借りる。
```
- **25年キャリア** の権威訴求 + 手軽さ
- 経営層・コンサル・意思決定者向け

#### 案③ 時間×品質軸（**僕らの基本推し**）
```
8時間の診断書を、5分で。
編集可能なPPTXで届く。
```
- **時間ROI（8時間→5分）× PPTX編集可能** の両立訴求
- 全読者層に耐性・Brain記事本文との整合性最強
