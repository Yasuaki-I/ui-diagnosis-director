# ヒーローバナー訴求ワード3案（v2・僕から提案）

**作成日**: 2026-07-13（月）
**更新**: 入江さんの指摘（GMB引っ張られすぎ・UI診断ディレクター本体にスコープ）を受けて再設計
**対象**: Brain販売ページ最上部のAI生成ヒーローバナー画像に載せるキャッチコピー
**ターゲット**: Brain読者（中小企業EC/LP運営者・制作会社・フリーランス・Webディレクター）
**制約**: 2短行・各行最大15字
**軸**: UI診断ディレクター本体にフォーカスした3つの切り口

---

## 設計思想の修正

### 前バージョンからの変更点
- **GMB連続性軸は削除**：GMBとUI診断ディレクターは同一レイヤーの商品ではないため、ヒーローバナーで訴求すると商品特性のフォーカスがぼやける
- **UI診断ディレクター本体にスコープ**：商品が **何をしてくれるか** を主軸にする
- **note経由読者・新規読者の両方に耐性**：どちらの読者にも即座に商品価値が伝わる

### 3案の軸再設計
| 軸 | 主眼 |
|---|---|
| ①機能ベネフィット軸 | 商品が **何をするか**（機能） |
| ②時間対価値軸 | 商品が **時間をどう変えるか**（体験変化） |
| ③到達価値軸 | 商品によって **何が実現するか**（結果） |

## 【案①】機能ベネフィット軸

### コピー
```
URLを送って、3〜5分。
提案書レベルの診断書が届く。
```

### 設計意図
- **1行目**：**操作の圧倒的な単純さ**（URLを送るだけ・3〜5分）
- **2行目**：**成果物の質**を「提案書レベル」の一言で保証（クライアント納品可能な品質）
- **キーワード**："送って"→"届く"の受動→能動リズム

### 訴求ロジック
- 一目で "What is it?" が伝わる **機能明示型**
- "3〜5分"という **具体的時間** で信頼感
- "提案書レベル"という **業界共通言語** で品質を保証
- **note未読・既読を問わず有効**

### 効果予測
- **BtoB購入意思決定者**：極めて高い訴求力
- **具体的な機能を確認したい読者**：高い訴求力
- **経営層**：中程度（機能的すぎる印象）

### 字数チェック
- 1行目：11字 ✅（15字以内）
- 2行目：14字 ✅（15字以内）

## 【案②】時間対価値軸

### コピー
```
8時間の診断書づくりを、
5分に圧縮する。
```

### 設計意図
- **1行目**：**現状の負担**（8時間の診断書づくり）を明示
- **2行目**：**変化の劇的さ**（5分に圧縮）を提示
- **キーワード**："8時間"→"5分" の **時間の圧縮率** で驚きを演出

### 訴求ロジック
- 読者の **現在の痛み**（8時間の負担）に共感
- **具体的な数字**で信頼感（8時間・5分の対比）
- **時間節約価値** = 直接的なROI訴求

### 効果予測
- **業務多忙な実務者（Web制作会社・フリーランス）**：極めて高い訴求力
- **時間ROIで意思決定するBtoB購入者**：高い訴求力
- **時間よりも品質を重視する読者**：中程度

### 字数チェック
- 1行目：11字 ✅（15字以内）
- 2行目：8字 ✅（15字以内）

## 【案③】到達価値軸

### コピー
```
"一応使える"を、
"提案できる"に変える。
```

### 設計意図
- **1行目**："一応使える" というBrain記事本文の **キーコピー** を最初に見せる
- **2行目**："提案できる" という **業務価値** への転換を明示
- **キーワード**："使える"→"提案できる" の一言変換で **道具の使命** を象徴

### 訴求ロジック
- 本文の思想を **1本の軸** に集約した象徴的コピー
- "使える"→"提案できる"で **業務利用への進化** を明示
- 抽象度が高いが、Brain記事全体の哲学を **入口で提示**

### 効果予測
- **経営層・意思決定者**：極めて高い訴求力（コンセプトで意思決定する層に刺さる）
- **業務利用を検討している読者**：高い訴求力（"提案できる"が刺さる）
- **具体機能を知りたい読者**：やや弱い（具体性が薄い）

### 字数チェック
- 1行目：8字 ✅（15字以内）
- 2行目：11字 ✅（15字以内）

## 【僕の推し・修正版】

**基本推し：案②（時間対価値軸）**

### 推し理由（修正版）
1. **数字の対比インパクトが圧倒的**（8時間 vs 5分 = 96倍圧縮）
2. **Brain読者の中心層** = Web制作会社・フリーランスの **時間コスト意識** に直接訴求
3. **note経由・新規読者を問わず即座に価値が伝わる**（GMB依存なし）
4. **§10「導入前と導入後で、時間はこう変わる」との内容一致**（Brain記事内での訴求整合性）

**サブ推し：案①（機能ベネフィット軸）**

### サブ推し理由
- **note未読の新規読者への訴求力が最強**
- **サムネイル・OGP画像との相性が良い**（"URLを送って"の明快さがSNS拡散に有効）

## 【前バージョン（v1）からの変更点】

| 項目 | v1 | v2 |
|---|---|---|
| 案① | GMB連続性軸（保存→納品） | 機能ベネフィット軸（URL→提案書） |
| 案② | 機能ベネフィット軸（URL→提案書） | 時間対価値軸（8時間→5分） |
| 案③ | コンセプト軸（使える→提案できる） | 到達価値軸（使える→提案できる・同じ） |
| 基本推し | 案①（GMB連続性軸） | **案②（時間対価値軸）** |
| 意図 | note経由読者への物語型接続 | UI診断ディレクター本体の価値訴求 |

**修正の核心**：
- GMB連続性は本文§1（「GMB note記事からの読者へ」）で十分カバーされる
- ヒーローバナーは **商品そのものの訴求** に集中すべき
- 「思想的な連携」と「商品としての別性」を混同していた
