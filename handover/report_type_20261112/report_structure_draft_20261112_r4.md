## 3. 型の検討（判定244-2 の B）
> 目的は欄の配置・情報量・見出しの付け方を決めること。**確認待ちの提案を、完成した提案らしく見せる作業にはしない**。各ページの中身は「枠と字数の目安」で示し、事例の文言は入れない

### 3-1. ページ構成（基本形・r2/r3 から変更なし）
1 前提／2 全体像／3〜5 提案（件数は根拠が整った数。0〜5件）／6 確認が必要なこと／7 付録：点数の根拠と限界

### 3-2. 1ページ目：前提
| 領域 | 位置 | 情報量の目安 | 見出し |
|---|---|---|---|
| 3区分の表 | 左 約6割 | 7行×3列。1セル 最大2行 | 「依頼者回答」「未確認」「診断側の提案」 |
| 今回想定する利用者 | 右上 | 3〜4行＋定型の1行（「この想定で改善案を検討します。実際の利用者像は未確認です。」） | 「今回想定する利用者（診断側の提案）」 |
| 行動の流れ | 右下 | 6段の名前だけ | 「検討する行動の流れ（元記録を基に整理）」 |
| 確認範囲 | 最下段 1行 | 1行 | 「確認した範囲」 |

### 3-3. 2ページ目：全体像
| 領域 | 情報量の目安 | 見出し |
|---|---|---|
| 行動の流れ（6段）の帯 | 段名のみ | 1ページ目と同じ |
| 提案の一覧（帯の下、該当段の下に配置） | 1件1行の見出し＋購入との関係（1語） | 「今回説明する提案（既存5提案から選定）」 |
| 確認待ち・確認事項の件数 | 1行 | 「確認が必要なこと：〇件（6ページ目）」 |
| 参考の点数 | 隅に1行 | 「参考：総合〇/50・ランク〇（算出方法は付録）」※事例としての掲載確定は保留（判定244-5） |
- 提案が0件の場合：一覧の領域に「確認が済んだ提案はありません（6ページ目参照）」と1行。空欄を埋めるための仮の提案は置かない

### 3-4. 3〜5ページ目：提案（1件1ページ）
| 領域 | 位置 | 情報量の目安 |
|---|---|---|
| 現在位置（6段の該当段を強調） | 上端 | 図のみ |
| 見出し | 上 | 1行・25字前後 |
| 画面 | 中央 幅9割前後 | 着眼箇所に番号の印 |
| 3列「画面で確認したこと／つまずきそうな点／改善の方向」 | 画面の下 | 各 2〜3行 |
| つながり | 最下段 | 1行（想定利用者・段階・購入との関係） |
| 確認が必要なこと | 最下段 | 1行（採否を左右するものだけ） |
- 列1が空欄・未確認の候補は、提案ページにしない（6ページ目へ）
- 見出しは課題を言い切る形。ただし列1で確認した範囲を超えない

### 3-5. 6ページ目：確認が必要なこと
| 列 | 内容 |
|---|---|
| 項目 | 候補の名前、または未確認のヒアリング項目 |
| 何が足りないか | 1行（例：対象の画面が今回の保存資料に見当たらない） |
| 確認の方法 | 1行（例：対象画面の提供を受ける） |
- 検証手順の詳細（判読対象・測定値など）は載せない。内部記録へ

### 3-6. 7ページ目：付録（点数）
- 10項目の点・算出式・ランク基準（採点ルール原本から転記）・限界（別回の36点の存在、記録上の限界、過去の記録で現在の評価ではない）
- 採点ルール本体は、必要な提出時に統括の原本照合を受ける（記録配置は連鎖させない）

### 3-7. 見出し・欄名の一覧（決めたいもの）
| 欄 | 案 |
|---|---|
| 前提の3区分 | 依頼者回答／未確認／診断側の提案（了承済みは「・依頼者了承」を付記） |
| 想定利用者 | 今回想定する利用者（診断側の提案） |
| 行動の流れ | 検討する行動の流れ（元記録を基に整理） |
| 提案の3列 | 画面で確認したこと／つまずきそうな点／改善の方向 |
| 提案の最下段 | つながり／確認が必要なこと |
| 全体像の一覧 | 今回説明する提案（既存5提案から選定） |
| 点数 | 参考：総合〇/50・ランク〇（算出方法は付録） |
