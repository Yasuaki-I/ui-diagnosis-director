## 3. 設計の原則（4観点）

### (a) 情報の優先順位・一目で分かる構成

**① 3.2 載せるべき情報を整理する（印刷 p.17–20）**
必要情報とグラフ候補を一覧化し、「載せるべき情報を選ぶ際の原則」（p.18 ※判定246 で統括が公式PDF本文を確認し p.20 から訂正。p.20 は「骨格となるレイアウト」）に沿って選別する。目的に当てはまらない情報はできる限り取り除き、情報が判断や行動につながるまでの距離を縮める。加えて分解できる（全体→部分へ分割できる粒度）、違いに気づける（突出するデータ、変化の時期と傾向）、鮮度が高い（最新データを反映）を条件とする。

**② 3.3 プロトタイプを作る「骨格となるレイアウト」（印刷 p.19–20）**
整理した必要な情報を、情報の優先度と関係性を考慮してレイアウトし、優先度に応じて目立たせたり、大きさや順番を決める。情報量が多い場合はページを分割したりナビゲーションを設計する。骨格となるレイアウトが定まないうちに表層の表現を詰めることは推奨しない。

**③ 「ダッシュボード設計の原則」（印刷 p.22）**
4項目：**構造を伝える**（全体から部分へと階層構造に整理し、最初に全体を示す情報を得られ、次にその詳細へ辿り着けるようレイアウトや導線を設計）／**適切な情報量にする**（過多な情報で継続的な利用意欲を削がないよう情報の総量を調整）／**複雑な操作を要求しない**／**比較対象を提供する**（目標値・平均値・前年値・前年比を併記）。

**④ 3.4 レイアウトの考え方（印刷 p.23）★本項の中心**
> 「ダッシュボードのレイアウトは、見る人の視線の動きに合わせるように、左上から右下に向かって、全体から部分が並ぶように配置します。左上では全体を端的に示し、右下では最も詳細な情報を表示するようにします。また、背景色に差をつけ、左上が最も目を引くように表現を調整します。」

**⑤ 4.4 グラフ設計の原則「強弱をつける」（印刷 p.39–40）**
重要な情報には、それ以外とは異なる表現（色やサイズ、文字の太さなど）を用い、見る人の注意を喚起して必要な情報を発見しやすくする。

**⑥ 4.5 Do’s「全体の指標と詳細のグラフを表示する」（印刷 p.42–43）**
見る人が最初にデータの全体像を捉えられるよう、全体を表す指標を配置し、その詳細についての表やグラフを配置する。Don’t 側の注記は「詳細の要素だけが並んでいる」。

**⑦ 5.4 チェックリスト（印刷 p.53）**
「利用者が見たいと思っている数値へ優先的に目が向くくなっていますか？」「データの全体像を捉えるための基準となる指標が掲載されていますか？」「利用者が迷わず必要な情報まで辿り着けますか？」

### (b) レイアウト（揃え・グリッド・余白・繰り返しの表現）

**① 3.4 レイアウトの考え方（印刷 p.23–25）**
- グリッド：縦横6分割が可能な**レイアウトグリッドをひいた16:9の画面用のテンプレート**を用意し、指標や表・グラフなどの構成要素をグリッドに沿って配置する（p.23）。図中の寸法注記は **1920px × 1080px**。
- 視線：「左上から右下へ、上から下へ、左から右へ等、見る人の視線に沿うかたちで、全体感を表す指標から詳細の情報へ流れるように設計します」（p.24）。
- 繰り返しの表現（フィルター）：「フィルターは基本的に画面の上部か左部に配置し、フィルターの影響を受ける情報はそれより下か右に配置します。フィルターと影響を受ける情報との関係性が分かるように配置しましょう」（p.25）。
- 背景色による階層（p.23–25）：左上の主要指標のみ濃い青背景とし、他と差をつける。

**② 5.2 レイアウトグリッド（印刷 p.51）**
「本書が提供するレイアウトグリッドは、16:9の画面を縦横に2～6分割できるように設計しており、目的に合わせて柔軟にレイアウトを組むことができます。デザインテンプレートから表やグラフをコピー&ペーストし、グリッドに沿ってサイズや位置を調整します。」

**③ 利用マニュアル（印刷 p.52 および 利用マニュアル本体 p.7・p.11）**
`.pbit` は3ページ構成（チャート・コンポーネントライブラリ／Layout (16:9) 1280×720／Layout (4:3) 960×720）。最終工程に「グリッドを非表示にする」がある（手順7）。グラフは「グリッドに合わせて位置とサイズを調整します」（p.9）。

**④ 4.5 Do’s「不要な要素は削除する」（印刷 p.44）**
「情報の重複を避け、下地のグリッドは最小限にします。数値と直接関係のないテキスト情報は薄い色にし、グラフの情報量を必要最低限にします。」Don’t 例では不要な縦横グリッド・枠線・説明文・軸ラベル・不要な小数部を指摘。

**⑤ 5.4 チェックリスト（印刷 p.53）**
「チャートや表の配列順序が認知しやすいものになっていますか？」「チャートに含まれる要素（グリッドや枠線）を最小限にしていますか？」「チャートと凡例が隣接され、対応づけがわかりやすくなっていますか？」

**⑥ 「揃え（アラインメント）」について**
ガイドブック本文・チェックリスト・利用マニュアルのいずれにも「揃え」「アラインメント」という語の明示的記述は確認できない（**記載なし（未確認）**）。実質的な整列の基準として示されているのは、グリッドに沿った配置（p.23・p.51）、フィルターと対象情報の上下／左右の配置（p.25）、項目の並び順に意味を持たせる考え方（p.43。Do は数量の大小順など、Don’t はあいうえお順）。

**⑦ 「余白（ホワイトスペース）」について**
「余白」「ホワイトスペース」という語での明示的記述は確認できない（**記載なし（未確認）**）。対応する考え方は 4.5「不要な要素は削除する」「下地のグリッドは最小限にします」および 3.4「背景色に差をつけ、左上が最も目を引くように表現を調整します」に含まれる。

### (c) 色の使い方

**① 4.3 カラーパレット（印刷 p.35–38）**
- 7系統（Blue / Light Blue / Cyan / Green / Orange / Red / Solid Gray）を用意。デジタル庁デザインシステムのカラーパレットを踏襲（p.35）。
- 各色のステップ（50/200/400/600/900/1200、Solid Gray は 50/200/400/536/700/900）。凡例は「白背景（#FFF）を1とした時のコントラスト比。右に行く程コントラストが強くなります」（p.35）。
- **10色のみが設定されている**という設計。p.36 で10色の役割を固定：テキスト（Text Black #000000 / Text White #FFFFFF / Label #626264 / Link #0017C1）、背景（Standard #F8F8FB / Highlight / Control #F1F1F4）、チャート（Primary / Secondary / Neutral）、セマンティックカラー（Positive / Negative / Success #197A4B / Error）。
- **コントラスト比（p.38）**：「アクセシビリティに対応する場合、背景色とグラフ色面のコントラスト比を3:1以上にする必要があります」。3:1 を満たせない場合は (1) グラフの色面領域のすぐ近くに数値を記載（数値の色は背景色に対して **4.5:1以上**）、(2) グラフの色面領域をマウスオーバー／キーボードで触れた時に数値を表示。
- **色覚多様性（p.38）**：「グラフを多色にする場合は、色覚多様性の人の見え方を配慮する必要があります。カラーユニバーサルデザイン推奨の配色、色覚特性シミュレーションやチェッカーを活用し、見分けにくい色の組み合わせがないように調整します。また、色以外での識別方法を提供するようにしましょう。」
