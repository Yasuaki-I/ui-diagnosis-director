# 終業タスクフロー（2026-07-02 確定）

毎日の終業時に必ず以下の順で対応する。

## 1. 成果物 ZIP 化
- ファイル名：`_deliver/ui-diagnosis-director_YYYYMMDD.zip`
- 内容：`gpts-package/`, `_verify/`, `HANDOVER_YYYYMMDD.md`, `PROJECT_STATE.md`, `README.md`

## 2. HANDOVER_YYYYMMDD.md 作成
- 場所：`handover/HANDOVER_YYYYMMDD.md`
- 内容：本日の目的・実装した変更・検証結果・変更ファイル一覧・次回予定

## 3. PROJECT_STATE.md 更新
- 大きな決定・フェーズ切替時のみ
- 通常の日次進捗は HANDOVER に集約

## 4. 本日のまとめリスト（冗長ゼロ・箇条書き）
```
### ✅ 今日やったこと（3-5項目）
- ...

### 💡 発見したこと（2-3項目）
- ...

### 🎯 明日・次回やること（3-5項目）
- ...
```

## 5. Claude-Chat への申し送り（リスト形式）
Claude-Chat は入江さんの全PJ横断・統括役。
```
【Claude-Chatへ】UI診断ディレクターPJ本日の要点：
- 進捗ステータス：...
- 完了マイルストーン：...
- 未解決ブロッカー：...
- 他PJとの依存関係：...
- 明日の主要タスク：...
```

## 6. ヴァイオレットちゃん（OpenClaw）への申し送り（スケジュール）
ヴァイオレットちゃんは全PJスケジュール一括管理役。
```

- 本日消化タスク：...
- 明日予定タスク：...（見積り: X時間）

- リスケ要請：あり／なし
```
