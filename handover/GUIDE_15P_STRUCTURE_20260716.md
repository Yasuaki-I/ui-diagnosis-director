## 🎯 このガイドの位置づけ

### 販売ページでの役割

- **Brain販売ページ §9「使い方」末尾**で「詳細ガイドは購入後に配布します」と誘導

### 設計思想

Claude-Chatの5つのセクション構造を採用：

1. **はじめに**（1-2P）：ガイドの位置づけと商品概要
2. **Section 1：基本操作**（3-5P）：初回利用の摩擦を極限まで下げる
3. **Section 2：出力物の理解**（6-8P）：3ファイルの読み方・活用方法
4. **Section 3：応用と対話**（9-11P）：本商品の対話機能・クライアント転用の訴求ポイント
5. **Section 4：トラブルシューティング**（12-14P）：URLアクセスUX改善（Instructions v3.3の4種エラーテンプレ）と連動
6. **おわりに**（15P）：アップデート情報の受け取り方

- 4事例構成（フォーマット見本3種＋実診断1件）を **ガイドのSection 2でも参照**

## 📐 制作仕様

### PDFフォーマット

| 項目 | 設定 |
|---|---|
| ページサイズ | A4横（29.7cm × 21cm） |
| フォント | メイリオ 14pt以上（本文）/ 18pt以上（見出し）/ 24pt（ページタイトル） |
| カラースキーム | NAVY #1C366C 基調（UI診断ディレクターと統一） |
| ページ番号 | 右下に配置（例：「03 / 15」） |
| フッター | 「UI診断ディレクター 使い方ガイド」（右揃え） |

### 制作方法（推奨）

**案A：PowerPoint → PDF出力**（推奨）
- 既存のPPTX資産（v15.5デザイン基準）をそのまま流用可
- レイアウト微調整が容易
- 所要：60-90分

**案B：Canva / Figma でデザイン制作**
- ビジュアル自由度が高い
- 所要：120-180分（デザイン学習コスト含む）

**案C：Notion / Google Docs → PDF**
- 制作速度は最速
- デザイン品質は劣る
- 所要：30-45分（表紙のみ別途）

**私の推奨**：**案A**（PPTXベース）
- Brain販売ページの実物と統一感が出る
- 制作時間と品質のバランスが最適
- 修正・追加が容易
