# 採点ルール（詳細）
SKILL.md §2 の補足。迷ったときに参照する。

## 1. サイトの種類の判定
| 種類 | 手がかり | 対象外にする項目 |
|---|---|---|
| LP | 1ページ・申込みへの導線・縦に長い | なし |
| EC | 商品一覧・カート・価格 | なし |
| コーポレート | 会社情報・IR・採用 | なし |
| SaaS | プラン比較・機能説明 | なし |
| バナー | 画像1枚・ページの構造が無い | フォーム／レスポンシブ／読みやすさ／情報設計／表示速度 |
| その他 | 上のどれでもない | 当てはまらない項目だけ |
- 判定の順：画像の縦横比 → URL の構造 → ページ内の要素
- 判定結果は観点の提示のときに「今回は{種類}として診断します」と示す。訂正されたら判定し直して観点を出し直す
- 対象外の項目は score に `'－'`（文字列）を入れる

## 2. 10項目で見るところ
1. ファーストビュー：体験価値・成果が一瞬で伝わるか／FV 内の CTA
2. キャッチコピー：差別化・ベネフィットが明快か
3. CTA 設計：FV・中盤・末尾に主要 CTA があるか／文言が行動を促すか
4. 信頼性・権威性：実績・第三者評価などの根拠
5. フォーム設計：入力前の不安の解消／入力の負担
6. レスポンシブ：スマホへの最適化／スマホで固定される CTA など
7. 読みやすさ：余白・行間・色数・文字の大きさ
8. 情報設計：特徴・比較・成果・不安解消がそろっているか／順序
9. ブランド一貫性：配色・書体・語調が業種に合い、そろっているか
10. 表示速度・技術：画像・コードの最適化

## 3. 5段階の基準
| 点 | 基準 |
|---:|---|
| 5 | 業界トップクラス／改善の余地がほぼ無い |
| 4 | 良好／軽い改善の余地 |
| 3 | 標準的／中くらいの改善の余地 |
| 2 | 改善が必要／成果に影響がある |
| 1 | すぐに対応が必要／致命的 |

## 4. 総合点・ランク・ランクの説明
- 総合点＝（対象項目の合計÷対象項目の数）×10（50点満点）
| ランク | 範囲 | ランクの説明（rank_label・このとおりに） |
|:-:|---|---|
| S | 45〜50 | 卓越 |
| A | 38〜44 | 優良 |
| B | 30〜37 | 標準的 |
| C | 20〜29 | 要改善 |
| D | 0〜19 | 致命的 |

## 5. 強み・課題・結論
- 強み：4〜5点の項目から、成果につながる良い点を能動形で。各40字以内
- 最優先の課題：1〜2点の項目から、成果を妨げている点を課題の形で。各20字以内（C-1・C-3 とも1行）
- 件数：**強み・課題とも、ランクに関わらず各3件**（PPTX に載るのは3件まで）。C-1 の課題・C-3 の課題・C-3 の top_issues は**必ず同じ3件**
- ランク C・D で課題が3件に収まらないときは、成果への影響が大きい順に3件を選び、残りは改善提案（5件）と結論に反映する
- 結論：最優先の改善の方向と期待できる効果を、60字以内の1文で
- 結論・改善方向（direction）・改善提案のまとめ（summary）の文の形：
  - 判断を含む1文にする（「〜すべきだ」「〜が見込める」など）。「A。B」と2文に分けない
  - 「〜について」のような題名で終わらせない
  - ダッシュ（「——」）を使わない。「本資料」などの自己言及をしない。「課題は3つ」のような数え上げをしない
- C-3 の総評（summary）は上の文の形の対象外。**全角17字以内の1行の標語**（例：「FV内CTA追加で無料体験へ誘導」15字）

## 6. 改善提案（5件・バナーは3件でも可）
- 各提案の項目：no（1〜5）／title（動詞で終える・36字以内）／priority（高・中・低）／effort（小・中・大）／target_area・issue（各25字以内）／before・after（各40字以内）／target_score_item（10項目の名前）
- 優先度：高1〜2件／中2〜3件／低1件。高から順に並べる
- まとめ（summary）：5件を通した「最優先の一手」を120字以内で

## 7. してはいけないこと
- 架空の数値・実在しない受賞歴や実績を書く
- 採点を交渉で変える（観点の漏れの指摘なら再診断、言い回しの修正は受ける）
- ページが読めないのに推測で採点する（dialogue_templates.md の E1・E3）
