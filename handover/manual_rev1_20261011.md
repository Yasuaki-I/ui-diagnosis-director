3. 次のコマンドで、ライブラリが入ったことを確かめます。版番号が表示されれば準備完了です。

## 3. はじめての生成（ファネル図を1枚つくる）
1. 同じフォルダに、次の内容で `run_sample.py` を作ります。
```python
import importlib.util
spec = importlib.util.spec_from_file_location('pptx_builder', '03_pptx_builder.py')
b = importlib.util.module_from_spec(spec)
spec.loader.exec_module(b)

palette = b.get_theme_palette('Blue')
prs = b.create_presentation()
data = {
    'title': '購買ファネルの段階別転換',
    'stages': [
        {'label': '認知', 'score': 80, 'description': '広告・SNSからの流入', 'value': 10000, 'unit': '人'},
        {'label': '興味', 'score': 65, 'description': '商品ページの閲覧',   'value': 4000,  'unit': '人'},
        {'label': '検討', 'score': 50, 'description': 'カート投入',         'value': 1200,  'unit': '人'},
        {'label': '購入', 'score': 40, 'description': '購入完了',           'value': 300,   'unit': '人'},
    ],
    'cumulative': 'auto',
    'footnote': '出所：自社アクセス解析（2026年4〜9月平均）',
}
slide, report = b.add_diagram_slide(prs, 'funnel', palette, data, page_num=1, total=1)
prs.save('04_Diagram_sample.pptx')
for n in report['notes']:
    print(n)
```
2. 実行します。
```
python run_sample.py
```
3. フォルダに `04_Diagram_sample.pptx` ができていれば成功です。画面には、描画の記録（notes）が表示されます。
```
通算指標を描画（v17.2.15｜→ 通算 3.0%（10,000→300人））
注記を描画（v17.2.16｜2行／収容 4行）
段数 4｜幅比 0.90→0.40 で絞り込みを表現
密度強化を適用（v17.2.4｜転換率・離脱量・打ち手）
```
- この読み込み方（`importlib`）では、ライブラリ末尾のデモは動きません。作業フォルダにできるのは `04_Diagram_sample.pptx` だけです。
- 本体の版は次のコマンドで確かめられます（`17.2.17` などと表示されます）。
```
python -c "import importlib.util as u; s=u.spec_from_file_location('b','03_pptx_builder.py'); m=u.module_from_spec(s); s.loader.exec_module(m); print(m.__version__)"
```
- テーマ（色）は `get_theme_palette()` に名前を渡して選びます。選べる名前は次の7つです：`SolidGray`／`Blue`／`LightBlue`／`Green`／`Cyan`／`Red`／`Orange`。これ以外の名前を渡すと、グレー系（`SolidGray`）で描画します。
- 段の数は **3〜6**。範囲外のときは、分類図（category）に自動で切り替えて描画します（エラーにはしません）。

## 4. 任意の設定 `cumulative`（通算の指標）
ファネル図（`funnel`）だけで使える設定です。指定しなければ、図は変わりません。

| 書き方 | 結果 |
|---|---|
| 指定しない／`None` | 表示しない |
| `'auto'` | タイトル行の右端に「→ 通算 X%（先頭の値→最後の値＋単位）」を自動で表示します。**すべての段に `value` があり、どれも0以上で、最初の段の値が0より大きい**ときに使えます |
| 文字列（例 `'通算 3%'`） | その文字列を、先頭に「→ 」を付けて表示します |

- X が10未満なら小数第1位まで、10以上なら整数で表示します（四捨五入）。
- **タイトルが長く、表示がタイトルとぶつかる場合は表示しません。** このとき notes に「省略（タイトルと衝突）」と出ます。表示したいときはタイトルを短くしてください。

## 5. 任意の設定 `footnote`（注記・出所）
ファネル図（`funnel`）だけで使える設定です。指定しなければ、図は変わりません。

| 書き方 | 結果 |
|---|---|
| 指定しない／`None`／空の文字列 | 表示しない |
| 文字列 | 最下段の左の空きに表示します。先頭が「※」でなければ「※」を付けます |

- **入りきらない長さのときは表示しません。** このとき notes に「注記を省略」と出ます。短くするか、段の数を減らしてください（段が多いほど、入る行数は少なくなります）。

## 6. うまくいかないとき
| 症状 | 確認すること |
|---|---|
| `ModuleNotFoundError: No module named 'pptx'` | §2 の `pip install python-pptx` を実行したか |
| `FileNotFoundError` | `03_pptx_builder.py` と `run_sample.py` が同じフォルダにあり、そのフォルダで実行しているか |
| 作業フォルダに `test_` で始まる PPTX が5つできた | `importlib` ではなく `exec()` で読み込んでいないか（§3 の書き方で読み込むとできません）。できたファイルは削除してかまいません |
| 通算の指標・注記が出ない | 画面に表示された notes に「省略」の理由が出ていないか（§4・§5） |
| タイトルが2行になり、図に重なる | §8-1 |
| 14pt 未満の文字を指定してエラーになる | 本ライブラリは14pt未満の文字を受け付けません（仕様） |

## 8. 運用上の注意
### 8-1. タイトルは短めに（目安：全角38字以内）
- タイトルは1行で表示する前提でレイアウトしています。**長いタイトルは2行に折り返し、2行目が図（ファネルの最上段など）に重なることがあります。**
- 試走では、全角40字までは1行、全角42字で2行になりました。英数字・記号が混ざると幅が変わるため、**全角38字以内**を目安にし、生成後に PowerPoint で1行に収まっているか確かめてください。
- 長くなる場合は、補足をタイトルから外し、段の説明（`description`）や注記（`footnote`）に移してください。
- タイトルが長いと、§4 の通算の指標も表示されなくなることがあります（notes に「省略（タイトルと衝突）」）。

### 8-2. 出所の書き方（注記 `footnote` を使う）
- 出所・集計期間などは、**タイトルや段の説明に書かず、`footnote` に書いてください。** 注記は最下段の左の決まった位置に自動で置かれます。位置を手で動かす必要はありません。
- 注記の入る行数は段の数で変わります。試走では、段が6つのとき2行まで入り、全角14字で1行、16〜20字で2行でした。**段が多い図ほど、注記は短く**してください（例：「※出所：自社GA4（2026年4〜9月）」）。
- 入りきらない場合、注記は表示されません（§5）。
