## 3. どう確かめるか（判定方法）
| 論点 | 判定方法 |
|---|---|
| 伝わるか | 想定する読み手が、番号ごとに「**場所・問題・改善の方向**」を、口頭の補足なしで説明できるか。番号ごとに〇／△／×で記録する |
| 評価者 | 入江さんが評価する。記録には「**開発者自身による評価**」と書く。初めて見る人で検証したことにはしない（判定202-4） |
| 画像の忠実さ | 元の画面を作り替えない（色・文字・配置を描き直さない）。注釈（番号・枠・指示線）は元の画面と区別できる色と線にする。切り出し・拡大の範囲と倍率を記録する |
| 読めるか | 表示環境：Windows の PowerPoint、スライドショー表示（画面いっぱい）と、標準表示の100%。確かめる方法：番号・指示線・説明の文字・画像の中の文字（分類名など）が読めるかを、入江さんが目で見て〇／×で記録する。画像で保存して記録に残す |
| 番号と箇所の対応 | 番号ごとに、指している箇所が説明と合っているかを〇／×で記録する |
| 事実と推測の区別 | 推測に「推測」の表示があるかを〇／×で記録する |

## 4. 試す回数と再現性
- **試験1（表現が成り立つかの確認）**：作るのは**最大2回まで**。1回目で条件を満たさなかった場合に、入力（指示文・指摘の書き方・切り出しの範囲）だけを直して2回目を1回だけ作る。3回目は作らずに止める
- **再現性の確認は試験1とは分ける**。試験1が成り立ったあと、別の承認で行う（案：同じ入力・同じ指示文で、新しいチャットを開いて2回作り、§3 の項目を同じ方法で比べる）
- 「作るたびに結果が大きく変わる」は、1回だけでは評価しない（判定202-4）

## 5. どこで止めるか（中止の条件と止まったときの扱い）
**止める条件**
1. 番号と指摘の箇所の対応が崩れる
2. 画像の文字・番号・指示線が読めない
3. 事実と推測が混ざる
4. 元の画面が作り替えられている（描き直し・文字の書き換え）
5. 添付した画像を、生成の処理が読めない
6. 権限・通信・追加の設定が必要になり、それが承認の範囲の外である。**避けるための設定変更は始めない**（判定202-4）
