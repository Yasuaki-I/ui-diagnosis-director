## 5. 表示条件（項目A の確かめ方｜判定219-3）
- Windows の PowerPoint で開き、①標準表示「ウィンドウに合わせる」②スライドショー（全画面）の2つで見る
- 記録すること：画面の解像度、表示倍率、PowerPoint の版、スライドの寸法（16:9）
- 補助として、PowerPoint から 1920×1080 で画像保存し、その画像の B・md5 を記録する
- 生成側の環境でメイリオが無い場合は、その旨を記録し、評価は Windows の PowerPoint での表示で行う
