## v3の設計思想

### 核心の対比構造（入江さんの戦略指摘）

| 観点 | 競合：デザイン分解GPTs | UI診断ディレクター |
|---|---|---|
| デザイン面 | 強い | （正直、劣る） |
| 出力形式 | 画像/テキストが主流 | **PPTX（編集可能）** |
| 業務利用 | 加工が必要 | **そのまま提案書に組み込める** |
| 視点 | デザイン分解に特化 | **Webディレクター視点（25年経験）** |
| 訴求核心 | デザインの美しさ | **業務利用の実装力・実務即応性** |

### 3案の軸再々設計

3案とも、以下いずれか2要素を組み合わせる：
- 【PPTX/編集可能】＝業務即応性
- 【ディレクター視点/25年】＝実務品質保証
- 【時間/圧倒的スピード】＝ROI訴求

| 軸 | 主眼 |
|---|---|
| ①業務即応軸 | **PPTX編集可能** の圧倒的利便性 |
| ②実務品質軸 | **ディレクター視点** の課題抽出力 |
| ③時間×品質軸 | **時間短縮×提案書品質** の両立 |

## 【案①】業務即応軸（PPTX編集可能性の核心訴求）

### コピー
```
編集できるPPTXで届く、
"実務で使える"診断書。
```

### 設計意図
- **1行目**：**「編集できるPPTX」** = 競合との差別化の核心
  - "編集できる"を先出しすることで、画像出力型競合との差別化を暗示
  - "PPTX"を明示することで、業務利用者に即座に価値が伝わる
- **2行目**：**"実務で使える"** = 業務即応性の直接明示
  - "診断書"という業界共通言語で商品価値を明確化

### 訴求ロジック
- **「編集できる」→「実務で使える」** の因果連鎖で価値を積み重ね
- 業務利用者（Web制作会社・フリーランス・コンサルタント）に **即座に響く言語**
- **デザインの美しさで勝負しない・実装力で勝つ** という商品ポジショニングを凝縮

### 効果予測
- **Web制作会社・フリーランス**：極めて高い訴求力（PPTX編集可能性が業務即応性そのもの）
- **クライアント提案書業務者**：極めて高い訴求力（"実務で使える"が刺さる）
- **経営層**：中〜高（PPTXの重要性を認識している層に刺さる）
- **デザイン専門家**：中程度（デザイン訴求ではないため反応薄）→ ただし本商品のターゲットではない

### 字数チェック
- 1行目：13字 ✅（15字以内）
- 2行目：13字 ✅（15字以内）

## 【案②】実務品質軸（Webディレクター視点の訴求）

### コピー
```
25年のディレクター視点を、
URL1本で借りる。
```

### 設計意図
- **1行目**：**"25年のディレクター視点"** = 実績と権威の直接明示
  - 開発者の実績（25年キャリア）を訴求主軸に
- **2行目**：**"URL1本で借りる"** = 操作の単純さ＋"借りる"という言葉で「知見の民主化」を暗示
  - "借りる" = 高額コンサルではなく、手軽な形で知見にアクセスできる示唆

### 訴求ロジック
- **知見の民主化**：本来なら高額コンサルに払うレベルの視点が、URL1本で得られる
- **信頼性の直接訴求**：25年 = 業界での実績・信頼の根拠
- **AI/GPTsの活用理由**を「開発者の視点をパッケージ化」として位置づけ

### 効果予測
- **経営層・意思決定者**：極めて高い訴求力（25年キャリアという肩書に反応）
- **コンサルタント・アドバイザー**：高い訴求力（"視点を借りる"に反応）
- **業務多忙な実務者**：中〜高（"URL1本で借りる"の手軽さに反応）
- **具体機能を知りたい読者**：中程度（機能訴求は薄い）

### 字数チェック
- 1行目：13字 ✅（15字以内）
- 2行目：10字 ✅（15字以内）

## 【案③】時間×品質軸（時間短縮×提案書品質の両立訴求）

### コピー
```
8時間の診断書を、5分で。
編集可能なPPTXで届く。
```

### 設計意図
- **1行目**：**時間圧縮のインパクト**（8時間→5分）＋ **成果物明示**（診断書）
  - 前v2案②の「圧縮する」より、"5分で。" の方が **即完了感**を演出
- **2行目**：**PPTX編集可能** の業務即応性を追加
  - v2案②では時間圧縮のみだったが、"編集可能なPPTX" を追加することで **品質保証** も同時訴求

### 訴求ロジック
- **時間ROIと業務即応性の両立** = 完璧な業務ツールの訴求
- 1行目で "興味を引く"、2行目で "実務性を保証"
- **v2案② + 案① を融合した最強候補**

### 効果予測
- **Web制作会社・フリーランス**：極めて高い訴求力（時間×PPTXの両方に反応）
- **業務多忙な実務者**：極めて高い訴求力（時間ROI最重視）
- **クライアント提案書業務者**：極めて高い訴求力（PPTXが刺さる）
- **経営層**：高い訴求力（時間ROIで意思決定する層に刺さる）

### 字数チェック
- 1行目：12字 ✅（15字以内）
- 2行目：11字 ✅（15字以内）

## 【僕の推し・v3版】

**基本推し：案③（時間×品質軸）**

### 推し理由（v3版）
1. **時間ROI × 業務即応性の両方訴求**：1本のコピーで2つの購入判断要素をカバー
2. **競合差別化の核心（編集可能なPPTX）を明示**：デザイン特化競合との差別化を暗示
3. **note経由読者・新規読者を問わず即座に価値が伝わる**（GMB依存なし）
4. **§7実物サンプル・§10導入前後の時間変化との内容整合**（Brain記事本文との一貫性）
5. **経営層・実務者・意思決定者すべてに耐性**

**サブ推し：案①（業務即応軸）**

### サブ推し理由
- **競合差別化の核心を最短で伝える**
- **サムネイル・OGP画像との相性が良い**（"編集できるPPTX"の一言で価値が伝わる）
- 案③よりも情報密度が低く、視覚的にシンプル

**参考：案②（実務品質軸）**

- 経営層・コンサル向けに特化した象徴的コピー
- ヒーローバナーではなく、**§6他ツール比較・§8こんな人に使ってほしい** の見出しコピーとして流用検討価値あり

## 【画像配置マップの検討観点（次タスクへの申し送り）】

ヒーローバナーが合意されたら、以下の観点で画像配置マップを作成：

### 現状の画像挿入予定（v4/v5編集版基準）
- ヒーローバナー：1点（AI生成・最上部）
- §7実物サンプル：4点（v15画像化・スコアカード/提案リスト/診断ボード/品質保証）
- 図版：計5点（大全v2テンプレ流用推奨）

### 検討すべき点
1. **§7 は現状が最適位置か？**
   - 案：§4「この商品が解決すること」の直後（納品物明示直後に実物を見せる）に移動する検討
2. **§6「他ツール比較」に競合対比図を追加すべきか？**
   - PPTX編集可能 vs 画像出力の対比図を挿入することで、ヒーローバナーの訴求を補強
3. **§10「導入前と導入後で、時間はこう変わる」に時間対比図を追加すべきか？**
   - 8時間 vs 5分の対比を視覚化して、ヒーローバナーの訴求を補強
4. **§12「価格と特典」に価格帯対比図を追加すべきか？**
   - Similarweb/SEMrush(月額) vs UI診断ディレクター(買い切り) の対比
5. **§13「最後に」の前に、購入判断の最終後押し画像を配置すべきか？**
   - 考察指摘：§13直前に「購入直前の5項目再提示」を追加すべき→ 図版化する価値あり

### 図版5点の推奨内訳（v3版）
1. **§4後**：3ファイル納品イメージ図（既定・大全v2 サービス紹介テンプレ流用）
2. **§6内**：競合比較図（PPTX編集可能 vs 画像出力）← 新規追加検討
3. **§10内**：時間対比グラフ（8時間→5分の圧縮効果）← 新規追加検討
4. **§12近く**：価格・特典まとめ図（段階的価格を採用する場合）
5. **§13直前**：購入判断の最終後押しサマリ図
