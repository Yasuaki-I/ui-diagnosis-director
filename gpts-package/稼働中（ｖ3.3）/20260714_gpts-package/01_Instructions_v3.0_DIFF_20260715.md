## 🎯 v2 Lite → v3.0 主要変更5点

### 変更1：PPTXファイル名の英数字化ルール（発注文 変更1対応）

**変更前（v2 Lite）**：
```
| C-1 | `01_UI診断スコアカード_{サービス名}.pptx` | 2枚固定 |
| C-2 | `02_改善提案リスト_{サービス名}.pptx` | 1〜2枚 |
| C-3 | `03_ビジュアル診断ボード_{サービス名}.pptx` | 3枚固定 |
```
日本語ファイル名を使用 → Code Interpreter → ChatGPT配布URL化時にパーセントエンコード発生 → ユーザーに文字化けが露見

**変更後（v3.0・J-1セクション新設）**：
```
| C-1 | `01_UI_Scorecard_{site_slug}.pptx` | 2枚固定 |
| C-2 | `02_Proposals_{site_slug}.pptx` | 1〜2枚（自動） |
| C-3 | `03_Visual_Board_{site_slug}.pptx` | 3枚固定 |
```
+ site_slug 変換ルール明記（半角英数字＋アンダースコアのみ）
+ 変換例：「スピークアップ英会話」→ `speakup_eikaiwa`
+ ユーザーへの1行告知：「ファイル名はダウンロード互換のため英数字表記」

### 変更2：C-3総評17字制約＋自動リトライ（発注文 変更2対応）

**変更前（v2 Lite）**：
K.絶対ルール内に「C-3：総評17字以内」という記述はあったが、判定・リトライロジックは未明記
→ Instructions内の summary サンプルは34字（「最優先の一手：ファーストビューに...」）で17字制約と矛盾

**変更後（v3.0・J-2セクション新設）**：
- **判定**：生成後に文字数カウントし、18字以上ならモデル内で自動リトライ再生成
- **書式**：「〇〇して、〇〇へ進める」形式の1行スローガン
- **良い例明示**：`FV内CTA追加で無料体験へ誘導`（15字）、`目的別導線を整え離脱を防ぐ`（14字）
- **悪い例明示**：`最優先の一手：ファーストビューに無料体験CTAを追加し...`（34字・機械的切断発生）
- 「やらない」条項に「C-3総評を18字以上で生成しない」を追加

### 変更3：対話継続案内テンプレート（発注文 変更3対応・最優先）

**変更前（v2 Lite）**：
納品メッセージは3ファイルダウンロードリンク＋スコア表示で終了。応答が単発で終わり、パートナー訴求（v5.2_public §13）と機能訴求（§9）の一貫性が欠ける。

**変更後（v3.0・I.対話フローの納品メッセージ形式に追加）**：
```
---

**続けて、以下のような相談も可能です：**
- [案1：文脈に応じた具体的な深掘り観点]
- [案2：改善提案の実装難易度や優先順位の再検討]
- [案3：別ページ・別視点での追加診断]

気になる項目があれば、お気軽にお声がけください。
```
+ 「案1〜3は文脈に応じて動的生成」の指示明記
+ 「絵文字装飾は使わない」の運用ルール明記
+ E1〜E4エラーテンプレートの末尾にも対話継続案内を必須付加

### 変更4：4種エラーテンプレート（発注文 変更4対応・次点必須）

**変更前（v2 Lite）**：
「URL取得失敗時：『URLが取得できませんでした。スクリーンショットをお送りください』と1度だけ依頼」の1文のみ

**変更後（v3.0・C.入力受付内に「エラー時の応答（4種テンプレート）」セクション新設）**：
- **E1. URL取得失敗**：クローラー拒否・SPA等→4方法の選択肢（スクショ推奨・別ページ・時間を置く）
- **E2. 診断対象タイプ不明**：バナー・画像1枚等の判定困難→タイプ選択肢を提示
- **E3. スクリーンショット読取困難**：画質不足・部分キャプチャ→再送依頼＋補助情報
- **E4. 生成に時間がかかる場合**：待機理由を明示し離脱防止（進捗表示の代替）

**共通トーン**：冷たくならない・原因と代替策を提示・末尾に対話継続案内（変更3）を必ず付す

### 変更5：進捗表示予約領域（発注文 変更5対応・v3.0では準備のみ）

**変更前（v2 Lite）**：
進捗表示の概念自体が未実装

**変更後（v3.0）**：
- 実挙動は変更しない（Claude判断2により、進捗表示の本実装はβテスト後判断）
- v3.0では本体版のI.対話フロー内にコメントアウト形式で予約領域を確保：
  ```
  <!-- 変更5：進捗表示予約領域（v3.0では準備のみ・実挙動は変更しない）
     将来βテスト後に本実装する場合、以下の位置に進捗中のインジケータ表示を組み込む。
     現在は E4 エラーテンプレートで代替。
  -->
  ```
- PLAIN版ではコメントブロックごと除去（実挙動に影響しないため）
- 現在は E4 テンプレートが進捗表示の代替として機能
