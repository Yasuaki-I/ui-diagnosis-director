このパッケージを使って **公開GPTs**「紺＆クリーン スライド作成」を立ち上げる手順を説明します。所要時間は **約10分** です。

## 🚀 セットアップ手順

### 事前準備

- **ChatGPT Plus 以上のアカウント**（無料プランではGPTsを作成できません）
- ブラウザで `https://chat.openai.com` にログイン

### Step 1: GPT を新規作成

1. 左サイドバーの「**Explore GPTs**」をクリック
2. 右上の「**+ Create**」ボタンをクリック
3. 「Configure」タブに切り替える（Createタブの会話形式ではなく、直接編集モード）

### Step 2: 基本情報を入力

| 入力欄 | 値 |
|---|---|
| **Name** | `紺＆クリーン スライド作成` |
| **Description** | `深い紺色を基調とした、企業向けスライドをPPTXで作成します。メイリオ・14pt以上・重複ゼロを徹底。` |
| **Profile picture** | （任意）紺色の四角アイコンなど |

### Step 3: Instructions を設定

1. `01_Instructions.md` をテキストエディタで開く
2. **全文をコピー**（Ctrl+A → Ctrl+C）
3. GPTs作成画面の **Instructions** 欄に **貼り付け**（Ctrl+V）

⚠️ 文字数が多いため、貼り付け後にスクロールして欠落がないか確認してください。

### Step 4: Knowledge にファイルをアップロード

1. GPTs作成画面の **Knowledge** セクションを探す
2. 「**Upload files**」ボタンをクリック
3. 以下3ファイルを **まとめて選択** してアップロード:
   - `02_design_spec.md`
   - `03_pptx_builder.py`
   - `04_layout_catalog.pdf`

アップロード後、3ファイルが Knowledge セクションに一覧表示されることを確認。

### Step 5: Capabilities を設定

「**Capabilities**」セクションで以下のチェック状態を確認:

| 機能 | 設定 | 理由 |
|---|---|---|
| **Code Interpreter & Data Analysis** | ✅ **必須でON** | python-pptx実行に必要 |
| Web Browsing | ⬜ OFF | 不要（PPTX生成には使わない） |
| DALL·E Image Generation | ⬜ OFF | 不要 |

### Step 6: Conversation starters（任意・推奨）

エンドユーザーが最初にクリックできる例として、以下を設定すると親切です:

```
1. Q2の販売戦略レビューを10枚で作って
2. 新規事業提案を8枚でまとめたい
3. 組織改革プランの構成案を相談したい
4. 必達13条項について教えて
```

### Step 7: 公開範囲を選択して保存

右上の「**Save**」ボタンをクリック。公開範囲を選択:

| 選択肢 | 説明 |
|---|---|
| Only me | 自分だけが使う（テスト用） |
| Anyone with a link | リンクを知っている人だけ（限定共有） |
| Public | **GPTストアに公開**（社外不特定多数） |

**初回は「Only me」で動作確認** → 問題なければ「Public」に変更することを推奨します。

## ✅ 動作確認テスト

GPTを公開した後、以下の3ケースで正しく動くか確認してください。

### テスト1: ヒアリング → 構成提示

```
[あなたの入力]
Q2の販売戦略レビューを10枚で作りたい。
著者は「○○株式会社 営業企画部」、日付は「2026年7月15日」。

[期待される応答]
GPTが10枚の構成案を文字で先に提示し、
「このまま生成してよろしいですか？」と確認してくる。
```

### テスト2: PPTX生成

```
[あなたの入力]
このままお願いします。

[期待される応答]
Code Interpreter が起動し、python-pptx で .pptx を生成。
ダウンロードリンクが提示される。
```

### テスト3: 品質確認

ダウンロードしたPPTXを **PowerPoint または Keynote で開く** → 以下をチェック:

- [ ] 全テキストがメイリオフォントで表示されている
- [ ] 最小フォントが14pt以上
- [ ] 文字や図形の重なり（意図的オーバーレイ以外）がない
- [ ] 表紙の日付・著者が右下に右揃え
- [ ] フッターに著者表記＋ページ番号が表示される

## 🔧 トラブルシューティング

### Q1. GPT が python-pptx の import エラーを返す

**A**: Code Interpreter で `!pip install python-pptx` を最初に実行するよう、Instructions の E章に明記されています。それでもエラーが出る場合、ユーザーに「`pip install python-pptx` を実行してください」と返すよう促されます。

### Q2. 生成したPPTXのフォントがメイリオでなく系統不明のフォントになる

**A**: 開いた環境（Mac の Keynote など）にメイリオフォントがインストールされていないと、代替フォントで表示されます。**Windows の PowerPoint で開けば正しく表示** されます。Mac で確認する場合は、メイリオフォントを別途インストールしてください。

### Q3. GPT が構成案の承認を取らずにいきなり PPTX を生成する

**A**: Instructions の C章「対話フロー」が効いていない可能性があります。Instructions 欄が正しく貼り付けられているか再確認してください。途中で切れていることがあります。

### Q4. レイアウトを追加したい

**A**: `03_pptx_builder.py` を編集して新しい `add_xxx()` 関数を追加 → Knowledge に再アップロード → Instructions の D章のレイアウト表を更新。

### Q5. ブランド色を変更したい

**A**: `03_pptx_builder.py` の冒頭にある配色パレット（NAVY, RED など）の `RGBColor()` を変更してください。例：紺を `#1C366C` から `#1A237E` に変更したい場合、`NAVY = RGBColor(0x1A, 0x23, 0x7E)` とする。

## 📞 更新・メンテナンス

このパッケージを更新する際は以下の手順で:

1. ローカルでファイルを編集（特に `03_pptx_builder.py` のテンプレ追加・修正）
2. `samples/build_samples.py` を実行して動作確認
3. PowerPoint で開いて品質チェック
4. GPTs作成画面の Knowledge セクションで該当ファイルを **削除 → 再アップロード**
5. Instructions に変更があれば、テキスト全体を **再貼り付け**
